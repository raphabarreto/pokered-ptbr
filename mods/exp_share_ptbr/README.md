# Exp Share (PT-BR)

Tradução para português brasileiro do mod Exp Share.

## 📋 Sobre

Compartilhamento de EXP para todo o grupo via menu OPTIONS. Escolha entre 4 modos diferentes de distribuição.

## 🎮 Funcionalidades

### Modos Disponíveis

**OFF** - Desligado (comportamento normal do jogo)

**GEN 1** - Estilo Exp. All clássico
- Lutadores dividem 50% do EXP
- Todo o grupo divide os outros 50%

**GEN 5+** - Estilo moderno
- Lutadores ganham 100% do EXP
- Pokémon no banco ganham 50% cada

**BALANCED** - Gen 5+ com limite
- Pokémon no banco só ganham EXP se estiverem **abaixo do level do lutador**

**AVERAGE** - Gen 5+ com média
- Pokémon no banco só ganham EXP se estiverem **abaixo da média do time**

### Compartilhamento Único

**COMPART. ÚNICO** permite escolher quem recebe o EXP compartilhado:
- **ALL** - Todos os pokémon no banco *(recomendado)*
- **1-6** - Apenas o pokémon naquela posição do time

## 📥 Instalação

1. Baixe [exp_share-ptbr-0.1.7.zip](../../packs/exp_share-ptbr-0.1.7.zip)
2. gen1recomp → MODS → Import mod .zip
3. Enable o mod
4. Reinicie o jogo

## ⚙️ Configuração

1. No jogo, abra **OPTIONS** (menu START)
2. Procure **"COMPART. EXP"**
3. Use LEFT/RIGHT para escolher o modo
4. Configure **"COMPART. ÚNICO"** se quiser (deixe ALL)
5. Salve e jogue!

## 🎯 Como Usar

1. Configure o modo desejado em OPTIONS
2. Monte seu time normalmente
3. Entre em batalha
4. Após vencer, você verá:
   - "POKÉMON ganhou X Pts de EXP!" (lutador)
   - "EXP compartilhado entre o grupo!" (banco)
