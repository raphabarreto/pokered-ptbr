# VersãoVermelha (Moves in English)

Brazilian Portuguese translation with **English move names** for a hybrid experience.

**Based on:**
- 📦 [bryanthaboi/versaovermelha](https://github.com/bryanthaboi/versaovermelha) - gen1recomp mod structure
- 🇧🇷 **Hyd~Traduções Pokémon Versão Vermelha v1.3.1** IPS patch - original translation

## ✨ Features

✅ **Story & Dialogues:** 100% Brazilian Portuguese  
✅ **Move Names:** English (TACKLE, SURF, THUNDERBOLT, etc.)  
✅ **Battle Text:** Portuguese (but move names stay in English)  
✅ **Items & Cities:** Portuguese  
✅ **NPCs & Trainers:** Portuguese  
✅ **Status Effects:** English labels (PSN, BRN, PAR, FRZ, SLP)

## 🎯 Why Moves in English?

- **Consistent** with competitive Pokémon terminology
- **Better for speedrunners and streamers** - international standard
- **Easier multiplayer communication** - everyone understands "Surf" and "Earthquake"
- **Clean, professional look** - matches modern Pokémon competitive scene
- **Prevents text overflow** - shorter names fit better in battle UI

## 🎮 Examples

**Battle Text:**
- ✅ "PIKACHU usou THUNDERBOLT!" (move name in English)
- ✅ "RATTATA foi envenenado!" (status in Portuguese)
- ✅ "CHARIZARD teve EARTHQUAKE inabilitado!" (mix of both)

**Dialogues:**
- ✅ 100% Portuguese - "Olá! Bem-vindo ao mundo dos POKéMON!"

## 📦 Installation

### Quick Install (Recommended)

1. Go to [Releases](https://github.com/raphabarreto/versaovermelha-moves-en/releases)
2. Download the latest `versaovermelha-moves-en-v*.zip` file
3. Open **gen1recomp** → **MODS** → **Import mod .zip**
4. Enable the mod (toggle **ON**)
5. **Restart the game** (close and reopen)

### Manual Install

1. Clone or download this repository
2. Zip the entire folder
3. Follow steps 3-5 above

## ⚙️ Compatibility

### ✅ Compatible With:
- Audio/Visual mods (SFXMusicReplacement, CryReplacement, etc.)
- QoL mods (running_shoes, repel_reuse, exp_share, etc.)
- UI mods (gen1_modern_ui, modern_bag, gen3_box, etc.)
- Gameplay mods (trade_evolution_fix, quality_of_life, etc.)

### ⚠️ Known Conflicts:
- **[CRYSTAL_251](https://github.com/Deftones565/gen1recomp-mod-crystal-251)** - Full Gen II overhaul that modifies translations, dialogues, and moves
  - **Why it conflicts:** Both mods modify the same text/translation files
  - **Workaround:** Disable CRYSTAL_251 to use this mod, or use CRYSTAL_251 alone (it's in English)
  - **Future:** We're investigating compatibility for a future version

## 🐛 Troubleshooting

**Problem:** Mod not loading / Everything in English  
**Solution:** 
1. Make sure the mod is **enabled** (toggle ON in MODS menu)
2. **Restart gen1recomp** completely (close and reopen)
3. Check if **CRYSTAL_251 is disabled**
4. Try disabling other translation mods

**Problem:** Text cutting off in battles  
**Solution:** This should be fixed in v1.0.0+. Make sure you have the latest version.
