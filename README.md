## 🎯 Como Instalar

1. **Baixe o mod desejado** na pasta [packs/](packs/)
2. Abra o **gen1recomp**
3. Vá em **MODS** → **Import mod .zip**
4. Selecione o arquivo `.zip` baixado
5. **Enable** o mod (toggle ON)
6. **Reinicie o jogo** (feche e abra)

## 🛠️ Contribuindo

Quer ajudar a traduzir mais mods? Veja o guia [COMO_TRADUZIR_MOD.md](docs/COMO_TRADUZIR_MOD.md)!

**Processo:**
1. Fork este repositório
2. Escolha um mod para traduzir
3. Traduza apenas as **strings de texto** (não mexa na lógica)
4. Teste no jogo
5. Abra um Pull Request
