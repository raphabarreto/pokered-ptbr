# Como Instalar Mods

Guia passo a passo para instalar mods traduzidos no gen1recomp.

## Pré-requisitos

- ✅ gen1recomp v0.1.38 ou superior
- ✅ Pokémon Red ou Blue original (ROM)

## Instalação via Interface (Recomendado)

### 1. Baixe o Mod

Vá para a pasta [packs/](../packs/) e baixe o arquivo `.zip` do mod desejado.

**Exemplo:** `exp_share-ptbr-0.1.7.zip`

### 2. Importe no gen1recomp

1. Abra o **gen1recomp**
2. No menu principal, vá em **MODS**
3. Clique em **Import mod .zip**
4. Selecione o arquivo que você baixou
5. O mod aparecerá na lista

### 3. Ative o Mod

1. Encontre o mod na lista (ex: "Exp Share (PT-BR)")
2. Clique no **toggle** para deixar **ON** (ligado)
3. O mod ficará marcado como **ENABLED**

### 4. Reinicie o Jogo

**IMPORTANTE:** Feche completamente o gen1recomp e abra de novo.

Mods só carregam quando o jogo é iniciado!

### 5. Verifique se Funcionou

Para o Exp Share:
1. Abra o jogo
2. Vá em **OPTIONS** (menu START)
3. Procure a linha **"COMPART. EXP"**
4. Se aparecer, está funcionando! ✅

## Instalação Manual (Avançado)

Se preferir instalar manualmente:

```bash
# Windows
Extraia o ZIP em: %APPDATA%\gen1recomp\mods\

# Linux
Extraia o ZIP em: ~/.local/share/gen1recomp/mods/

# Mac
Extraia o ZIP em: ~/Library/Application Support/gen1recomp/mods/
```

Depois reinicie o jogo.

## Desinstalação

1. Abra gen1recomp → MODS
2. Clique no toggle do mod para deixar **OFF**
3. (Opcional) Clique em **DISABLE** para remover completamente
4. Reinicie o jogo

## Problemas Comuns

### "Mod não aparece na lista"

- ✅ Certifique-se que baixou o arquivo `.zip` completo
- ✅ Não extraia o ZIP - importe ele diretamente
- ✅ Verifique se o gen1recomp está atualizado

### "Mod aparece mas não funciona"

- ✅ **Reinicie o jogo** (feche e abra)
- ✅ Verifique se o toggle está **ON**
- ✅ Alguns mods precisam de um **novo save** (rare)

### "Conflito com outro mod"

- ✅ Leia a descrição do mod - alguns conflitam
- ✅ Desabilite mods conflitantes
- ✅ Exp Share (PT-BR) conflita com "Exp Share" original
